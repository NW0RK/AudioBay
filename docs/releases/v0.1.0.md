# AudioBay 0.1.0 — Preview

First downloadable preview of the Android audiobook downloader.

- Browse and search the catalog, view book information and comments, and save books.
- Download torrents with queue controls, Wi-Fi-only mode, track selection and ETA.
- Publish verified audio into your chosen shared folder as Author/Book Title, preserving disc folders and Unicode names.
- Recover gracefully when the native torrent engine cannot load, including retries.
- Includes the refreshed glass interface and compact download setup.
- Add, replace or remove your own Gemini API key in Settings for AI name correction.

## Installation

Download and install `AudioBay-0.1.0-preview.apk` from the release assets. This APK
contains the ARM64 native torrent engine; native downloading requires Android 9+
on an ARM64 device. Android may ask you to allow installation from your browser.

Choose your audiobook destination folder in Settings. Android may restrict access
to Android/AudioBooks; select an allowed folder explicitly if necessary. Use a
separate audiobook player to listen to completed downloads.

## Preview limitations

This optimized, non-debuggable release build is signed with the existing local
development certificate. It is a preview, not a production signing arrangement.
Devices with a differently signed installation cannot update in place.

The shared APK excludes the developer's private Gemini API key. Add your own key
in Settings to enable name correction. Keys are encrypted using Android Keystore
and excluded from backups. Correction sends the entered names to Google and uses
your API quota. Manual author/title editing is always available. The app has no
built-in player.

Only download material you are authorized to obtain. Catalog availability and
public torrent connectivity depend on the remote services and peers.

## Verification

Release APK assembly, 95 JVM unit tests and release Android lint pass. The APK
signature and alignment are verified. SHA-256 checksums accompany the APK.
Device tests were not rerun for this release build.
