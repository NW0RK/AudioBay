# AudioBay 0.1.9

A new editorial design with opaque charcoal surfaces, bundled Manrope typography, cover-led shelves, compact rectangular controls, labeled navigation and a moving amber underline. Glass effects and circular tap ripples have been removed. Discovery results use a short fade and rise, and preference changes use a quiet sliding control. System animation scaling is respected.

Discover something new now generates personalized recommendations on demand using your Gemini key and completed download history. Picks resolve to real catalog entries and include brief explanations. History survives queue removal; Settings can clear it and cached recommendations. Personalization unlocks after the first completed download. Existing storage grants, shared files and legacy database tables are retained.

Validation: 129 JVM tests, debug lint and optimized public release build passed. Fifteen on-device checks cover discovery controls, history retention/backfill, database upgrade, navigation and dark/light visual fixtures. Live Gemini generation is not exercised by automated checks.

The public ARM64 APK excludes developer credentials and preserves the existing signing certificate for upgrades. Download the APK and SHA256SUMS.txt below.
