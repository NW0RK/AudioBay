# AudioBay 0.2

Search now opens fresh on every Search tap, with an empty focused field, keyboard ready, and recent-search suggestions retained. Back from a book still returns to its search results.

Book details show the entire cover at full width in the scrolling page. Back and Download remain accessible, and a compact title appears after the cover scrolls away.

Categories use the correct catalog addresses and separate Action, Adventure, Thriller and Suspense. Unrecognized category pages show a retryable error. Home cards show language and format together, with size below.

The launcher uses the newly generated ivory-book and amber-download icon on charcoal.

The public ARM64 APK excludes developer credentials and keeps the existing signing certificate for upgrades. Version name: 0.2.0 (required by the existing updater); version code: 11.

Validation: 132 JVM tests, lint, optimized public release build, and 10 connected-device UI tests passed. APK v2/v3 signatures and the previous release certificate match were verified. Live catalog requests from the build environment were blocked; category destinations were checked against the catalog's published navigation links.
