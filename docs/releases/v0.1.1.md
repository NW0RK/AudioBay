# AudioBay 0.1.1 — Preview

## Gemini key saving

- Accept pasted Gemini keys surrounded by quotes, whitespace or invisible edge characters.
- Check for an existing Android Keystore key before creating a first-use key.
- Verify encrypted persistence before reporting success, and restore the previous
  credential if replacement fails.
- Distinguish key-format, Android encryption and local-storage errors. Failed saves
  retain the entered text; no credentials are logged or included in this APK.

The original phone-specific failure could not be reproduced without a connected
device. These changes fix reproduced clipboard-format rejection and harden storage;
any continuing failure now identifies its category rather than blaming the key.

## In-app updates

- Check for new public GitHub releases from Settings or automatically when opened,
  at most once daily. Preview releases are included.
- Download only when requested, with progress, cancellation and retry.
- Verify checksum, package/version, device compatibility and signing certificate
  before offering installation through Android's confirmation screen.
- Keep verified downloads ready while granting installation access or after restarting
  the app. Failed/incompatible updates never trigger uninstallation.

## Install this version

Download `AudioBay-0.1.1-preview.apk` and install it over 0.1.0. This one manual update
adds the updater for future versions. The APK uses the same development certificate,
application ID and existing data storage; it remains an ARM64 preview build.

Open Settings → AI name correction to save your Google AI Studio/Gemini key.
Use Settings → App updates for later versions. Android may ask you to allow AudioBay
to install updates, then asks for final installation confirmation.

## Verification

Release assembly, all 115 JVM tests, release lint (no errors) and device-test APK compilation pass.
APK alignment and v2/v3 signatures are verified; SHA-256 accompanies the APK.
There was no connected Android device, so real key entry, optimized UI execution,
installer permission flow and preservation across an installed upgrade remain
unverified. The app remains a downloader with no built-in player.
