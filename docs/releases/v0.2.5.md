# AudioHarbour 0.2.5

- Clear, labeled Prepare download action on book details and a single Start download button in setup.
- Inline validation and focus guidance for missing book information, folder selection and magnet links.
- Queue failures stay with their download; completed items show their destination instead of transfer statistics.
- Confirm removal of unfinished downloads and use Retry saving for shared-copy failures.
- Dark, Light and System appearance choices; full-row Wi-Fi toggle and keyboard focus feedback.
- Recently added leads discovery before personal picks are available. Catalog metadata uses quieter supporting colors.
- Navigation adapts to narrow screens and large text without truncating destination labels.

Public build excludes private build-time credentials. Package identity, shared storage rules and the upgrade signing certificate are preserved. Version code: 16.
